# MenuPro

A restaurant menu management web application built as part of my Web Development internship task.

MenuPro gives restaurant staff one place to manage menu items, categories, inventory, pricing offers, dietary tags, menu versions, analytics, and reports. It also includes a customer-facing digital menu.

</div>

## GitHub Repository

[View the source code](https://github.com/notthatslayer/MenuPro/)

## Features

- Dashboard with menu and inventory overview
- Add, edit, and delete menu items
- Organize items into categories
- Track ingredient stock levels
- Create and pause special offers
- Manage dietary tags
- Save menu versions
- Basic menu analytics
- Menu and inventory reports
- CSV export for menu data
- Light and dark mode
- Responsive layout for desktop and mobile
- Login and registration screens
- Customer-facing digital menu

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Google Fonts
- Unsplash for menu imagery

## Project Structure

```text
restaurant-menu-management/
│
├── index.html
├── script.js
├── style.css
└── README.md
````

 - `index.html` contains the main application structure and screens.
- `script.js` handles the application data, rendering, navigation, forms, and interactions.
- `style.css` contains custom variables, theme styling, responsive behavior, and print styles.
- `README.md` contains the project documentation.

 ## Notes

 This version is a frontend-focused project. The application currently stores its data in JavaScript variables, so changes are not persisted after the page is refreshed.

 The inventory, analytics, menu views, and some other values are simulated to demonstrate how the interface would work in a real restaurant management system.
